# 복구

GRKit은 카메라의 전원이 꺼질 때까지만 카메라를 바꿉니다. 펌웨어에는 쓰지 않습니다.

## 카메라가 시작 중에 멈춥니다

1. 카메라의 전원을 끄십시오.
2. 카메라가 반응하지 않으면 배터리를 꺼냅니다.
3. SD 카드를 꺼냅니다.
4. 충전된 배터리를 넣습니다. 카드를 넣지 않고 전원을 켭니다.

렌즈 경통을 밀거나 당기지 마십시오. 공식 펌웨어를 업데이트하는 도중에는 전원을 끊지 마십시오.

## 그래도 카메라가 시작되지 않습니다

1. 카드를 넣지 않은 상태에서 재생 버튼을 길게 눌러 재생 모드로 카메라를 켭니다.
2. 메뉴가 열리면 카메라 설정을 초기화합니다. 초기화하면 개인 설정이 삭제됩니다.
3. 카드를 넣지 않고 다시 전원을 켭니다.

그래도 카메라가 시작되지 않으면 GRKit 사용을 중단하고 카메라 서비스 센터에 문의하십시오.
