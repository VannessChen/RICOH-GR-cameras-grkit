# ファームウェア書き出しツール

ファームウェア書き出しツールは、カメラが実行中のファームウェアイメージをメモリーからメモリーカードにコピーします。開発者はこのイメージを使って、GRKit がまだ知らないファームウェアのビルドに対応します。

このツールはメモリーを読み取るだけです。カメラ、ファームウェア、カメラの設定は変更しません。書き出したファイルにはリコーのファームウェアだけが含まれます。写真や個人データは含まれません。

対象は RICOH GR III、GR IIIx、GR IV と、それぞれの HDF モデルです。どのカメラでも同じ ZIP を使います。

## 始める前に

- SD スクリプトがオンになっている必要があります。GRKit をインストールすると、オンになります。GRKit をインストールしていない場合は、先にカメラのインストールガイドの手順 3 を行います。
- このツールがカードにある間、GRKit は読み込まれません。
- 充電済みのバッテリーを使います。

## ツールの入手

[最新リリース](https://github.com/ahonn/grkit/releases/latest)から `GRKit-<バージョン>-dump.zip` をダウンロードします。https://grkit.app の下部にある「ファームウェア書き出しツール」のリンクからも同じファイルを入手できます。

## ファームウェアを書き出す

1. カメラの電源を切ります。カードを取り出します。
2. カードの `SCRIPT` フォルダーをバックアップとしてコンピューターにコピーします。
3. ZIP の `SD_ROOT` の中身をカードのルートにコピーします。`SCRIPT/STARTUP.TTL` は置き換えます。
4. カードを入れます。通常どおり電源を入れます。MENU ボタンは押さないでください。
5. 2 分待ちます。その後、電源を切ります。
6. コンピューターで、カードの `SCRIPT/GRDUMP` を開きます。

フォルダーに `DUMP.OK` があれば、書き出しは完了です。フォルダーには約 20 MB の `RTOS.BIN` と `INFO.TXT` もあります。

フォルダーに `DUMP.ERR` があれば、書き出しは失敗しています。`DUMP.ERR` にはエラーコードが記録されています。この場合もフォルダーを送ってください。

どちらのファイルもない場合、カメラはツールを実行していません。SD スクリプトがオンになっていることを確認します。その後、手順 4 から 6 をもう一度行います。

## ファイルを送る

1. `SCRIPT/GRDUMP` フォルダーを ZIP に圧縮します。
2. ZIP を [GitHub issue](https://github.com/ahonn/grkit/issues) に添付します。カメラの機種とファームウェアのバージョンを書きます。

開発者が issue で書き出しを依頼した場合は、その issue に ZIP を添付します。

## カードを元に戻す

1. カードから `SCRIPT` フォルダーを削除します。
2. バックアップした `SCRIPT` フォルダーをカードにコピーします。

次に電源を入れると、GRKit が再び読み込まれます。
